# Changelog

All notable changes to MiniCount will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-XX-XX

### Added
- Initial release
- Event countdown tracking with custom dates and times
- Multiple widget sizes (Small 2x2, Medium 3x2, Large 4x3)
- Custom photo backgrounds from gallery
- 12 event categories with emoji icons
- Repeating events support (Daily, Weekly, Monthly, Yearly)
- Notification reminders before events
- Count up mode for past events
- 6 widget styles (Classic, Minimal, Bold, Elegant, Modern, Gradient)
- Material Design 3 UI
- Dark mode support with dynamic colors (Android 12+)
- Freemium model with 3 free events
- Premium upgrade ($1.99 one-time payment)
- AdMob integration for free users
- Google Play Billing integration
- Pin important events to top of list
- Event search and filtering
- Local data storage with Room database
- Data backup and restore support

### Features by Category

#### Event Management
- Create unlimited events (Premium) or up to 3 events (Free)
- Add custom titles, descriptions, and photos
- Select from 12 event categories
- Set specific dates and times
- Enable repeating events for birthdays/anniversaries
- Pin important events

#### Widgets
- Three widget sizes for different home screen layouts
- Real-time countdown updates (every 30 minutes)
- Custom photo backgrounds
- Color customization (8 preset colors)
- 6 different widget styles
- Tap widget to open app

#### Notifications
- Customizable reminder notifications
- Set days before event to be notified
- Special notification on event day
- Notification channels for different priority levels

#### Premium Features
- Unlimited events
- Ad-free experience
- All widget styles unlocked
- Premium themes
- Priority support
- One-time payment (no subscription)

#### Technical
- Kotlin with Jetpack Compose
- MVVM architecture
- Room database for local storage
- WorkManager for background tasks
- Hilt for dependency injection
- Glance for widget development
- Material Design 3 theming
- Dynamic color support
- Coil for efficient image loading

### Security
- All data stored locally on device
- No cloud sync or data upload
- Privacy-focused design
- Minimal permissions required

### Known Issues
- None at launch
